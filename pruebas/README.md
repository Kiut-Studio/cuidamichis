# Pruebas

`python3 pruebas/juego.py` abre el juego en Chromium (Playwright), con un reloj falso, y prueba: carga, nombre, cuidados, desgaste, finales, crecimiento, guardado, día/noche, tienda, minijuegos, reinicio, sonido, 8 tamaños de pantalla, modo sin conexión y manifest.
Opciones: `-k texto` (solo las que coincidan), `--capturas` (guarda imágenes en `pruebas/capturas/`).
